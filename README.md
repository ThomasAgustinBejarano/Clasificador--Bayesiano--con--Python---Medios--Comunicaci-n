# Clasificador--Bayesiano--con--Python---Medios--Comunicacion
Modelo de Naive Bayes y procesamiento de texto para la detección automática de noticias reales y falsas (fake news).

Este repositorio contiene un script en Python para la clasificación automática de titulares de noticias en las categorías real y fake. Utiliza técnicas de Procesamiento del Lenguaje Natural (NLP) mediante CountVectorizer para la extracción de características y un modelo de Naive Bayes Multinomial (MultinomialNB) para el entrenamiento y predicción de nuevos mensajes.
